3．部屋の状態の見方

③ 「現空」「空予定」「契約」などの意味

-->
「楽々賃貸」で物件検索の例

・現空 … 現在空室の部屋
・空予定 … 退去日が決まっている部屋（下に退去予定日が出ます）
・契約 … 現在入居者がいる部屋
・他済 … 他の不動産屋で契約している部屋
・大家使用 … 大家さんが貸し出しを止めている部屋
