電話に出る時の基本

  • 「タキザワ住販の〇〇でございます」で出る
  • わからない時は保留にして、対応可能な人に聞くか電話番号を聞き折り返す
  • 会社名や名前が聞き取れなければ「もう一度お名前よろしいでしょうか？」でOK
📡 必要な電話
▶物件確認不動産業者からの電話
  • 「物件名／部屋番号」をメモして楽々賃貸で確認
  • 居住用の内見方法を聞かれたら　➡　「イタンジからお願いします」
  • 事業用の内見方法を聞かれたら　➡　「名刺FAXでお願いします」
  • 広告掲載確認　➡　「広告掲載承諾書をFAXしてください」
  • 売買物件の確認　➡　対応可能な人へ聞くor取次ぎ。いなければ電話番号を聞き折返し
▶相談の電話一般の人から
  • 借りたい　➡　「受付表（名前・電話番号・条件等）」を聞いて折返す
  • 貸したい・買いたい・売りたい　➡　ある程度ヒアリングして、社長から折返す旨を伝える
▶解約の電話借主から
  • 「物件名（駐車場名）／部屋番号（区画番号）」を一応聞きタキザワ住販のホームページへ誘導する
  • 居宅・駐車場・事業用物件（事務所・店舗・工場等）の解約　➡　タキザワ住販のホームページの下部に解約フォームがあるのでそちらから送信してもらう　➡　メール(taikyo@)に解約通知が届くので印刷する
  • 高齢者等で入力できない人　➡　保留にして契約書を確認し、解約進行チェックリストに沿ってヒアリング
ITANDI解約マニュアル
▶更新の電話借主から
  • 「物件名（駐車場名）／部屋番号（区画番号）」を聞き保留にする
  • 居住用・事業用物件（事務所・店舗・工場等）の場合　➡　更新ファイルを探し状況を伝える
  • 駐車場の場合　➡　駐車場の更新は電子契約なので、招待メールが届いてるはずなのでマイページの登録へ誘導
    • 　　　　　　　　　よくわからなければ担当者から折返す旨を伝える。
ITANDI解約マニュアル
▶社長あての電話誰からでも用件確認
  • 「具体的な用件／名前」をメモして、在席なら繋ぐ
  • 不在なら電話番号も聞き、折返す旨を伝える
  • 営業電話か判断できない時は、実際にやり取りしている相手かを確認
▶従業員あて〇〇さんいますか
  • 対応可能そうであれば、そのまま取次いでOK
  • 不在・対応不可の場合は「名前、電話番号、用件」を聞いて折返し
▶駐車場の電話空き状況など
  • 「駐車場名・区画番号」を確認して楽々賃貸で検索
  • 現空・空き予定　➡　一度現地確認してもらい、その後に申込みへ案内
  • 申込　➡　「大変申し訳ございませんが申込が入っております」
  • 契約・他済　➡　「大変申し訳ございませんが現在契約中です」
  • オーナー使用・保留　➡　「大変申し訳ございませんが募集しておりません」
  • 初期費用は約3か月分、更新は1年毎、更新手数料は新賃料0.5か月＋税
  • 解約は1か月前通告、解約月は日割りなし
  • 更新時は電子契約に移行するため、マイページ開設が必要
📡 営業電話
▶営業電話サービス・広告など
  • 基本ワード：「大変申し訳ございませんが、弊社ではそのようなサービスを使う予定はございません」
  • しつこい時：「これ以上お話を伺うことが出来ません。必要であればこちらからご連絡いたします」

来客があった時の基本　➡　まず「いらっしゃいませ」と声をかける

👀 だれが来たかで判断する
▶お客さん初めて来た人・内見希望など
  • 「本日はどのようなご用件でしょうか？」と確認
  • 賃貸希望・売買希望をざっくり聞き、席へ案内して担当へ伝える
  • 慣れてきたら受付表に沿ってヒアリング
▶借主さん家賃・更新・相談
  • お名前と「どちらの物件の何号室か」を確認
  • 家賃支払い　➡　賃料と家賃帳を預かり、受取日・何月分・金額を記入して角印を押す
  • 受け取った家賃は金庫へ入れ、出納帳に記入
  • 社長個人所有物件は出納帳に記載せず、封筒に入れて社長机引出しへ
  • 更新料支払い　➡　更新ファイルを確認し、日付記入＆出納帳記入
  • 相談　➡　用件を聞いて、対応可能な人へ伝える
▶大家さんオーナー
  • 「いつもお世話になっております」と一言そえて用件を聞く
  • 物件名を確認し、お渡しボックスを確認する
  • 相談なら席へ案内して社長または対応可能な人へ伝える
  • 誰もいなければ内容を聞き、後日社長から電話すると伝える
▶営業・不動産業者業者対応
  • まず用件を確認する
  • 営業なら「資料だけお預かりしてお伝えします」でOK
  • 不動産業者の営業も同じく資料預かりでOK
  • 売買用地確認などは、売買している物件があれば資料を渡す
  • 契約書・重要事項説明書を製本テープでまとめる
  • 割印の場所　➡　表紙と裏面
  • 業者印　➡　タキザワ角印
  • 代表取締役または宅地建物取引士　➡　滝沢印

❓ よくある質問

楽々賃貸で物件名・号室を検索し、左下の状況欄で「現空」「空き予定」「契約」などを確認します。必要なら楽々賃貸マニュアルを開きます。
基本は約3か月分です。敷金1か月、賃料1か月、仲介手数料1.1か月が目安です。
駐車場は1年毎の更新で、更新手数料は新賃料の0.5か月＋税です。
居宅は物件により異なりますが、約6か月分です。敷金１か月、礼金１か月、賃料1か月、家賃保証会社１か月、仲介手数料1.1か月と火災保険２万前後が目安です。
まず物件名・部屋番号（または駐車場名・区画番号）を確認し、居室・駐車場ならホームページの解約フォームへ誘導します。
無理に答えず、保留にして「確認して折り返します」でOKです。慣れるまでは正確さ優先で大丈夫です。
