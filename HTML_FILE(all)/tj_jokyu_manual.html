上級編

書類作成と申込受付の中心業務です。まず賃貸か売買かを分けて考え、その後に作成方法へ進みます。

ステップ1（上級）
契約書作成
賃貸・売買を分けて作成
ステップ2（上級）
重説作成
賃貸・売買で確認事項が違う
ステップ3（上級）
申込用紙作成
申込受付から書類準備へ
上ステップ4（上級）
家賃保証会社
賃貸で必要な審査・申請対応
まず「賃貸」か「売買」かを決める
▶賃貸契約書の作成方法
  • 楽々で作成
  • 全日のテンプレで作成
  • 全日のWEB版で作成
▶売買契約書の作成方法
  • 全日のテンプレで作成
  • 全日のWEB版で作成
  • まず賃貸か売買かを確認する
  • 物件資料・法令制限・設備・特約など必要情報を集める
  • 作成方法は、賃貸なら楽々・全日テンプレ・全日WEB、売買なら主に全日テンプレ・全日WEBを使い分ける
  • 申込者情報、勤務先、緊急連絡先、入居希望日を確認する
  • 申込内容に不備がないか確認し、必要書類を案内する
  • 申込用紙作成後、保証会社審査や契約準備へつなぐ
  • 保証会社の種類、申込方法、必要書類を確認する
  • 審査依頼後、結果を確認して契約準備へ進める
  • 否決・追加書類・再申請時の流れも把握しておく
