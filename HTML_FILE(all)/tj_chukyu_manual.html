中級編

現場での対応が必要な業務です。まず全体の流れを見てから、個別の手順へ進みます。

ステップ1（中級）
駐車場の契約
申込用紙記入・免許証のコピー・車検証のコピー
ステップ2（中級）
居住用物件の申込受付
イタンジで申込受付or申込用紙・保証委託申込書・身分証のコピー
ステップ3（中級）
事業用物件の申込受付
申込用紙（個人or法人）・保証委託申込書・謄本（法人の場合）
ステップ4（中級）
内見
内見予約・鍵の所在・持ち物
ステップ5（中級）
退去立会
時間・物件・号室確認
ステップ6（中級）
原状回復工事依頼
写真・見積・工事依頼の流れ
    ①駐車場（個人or法人）の申込受付用紙を用意して、申込者に記入してもらう
    ②駐車場の契約進行表に沿って記入していく
    ③大家に申込が入ったことを連絡する
    ④免許証・車検証・謄本（法人の場合）のコピーをとる
    ⑤楽々賃貸で賃貸清算書を作成する
    ⑥楽々賃貸で駐車場契約書を作成する
    ⑦手の空いてる人に清算書の確認をしてもらう
    ⑧契約時費用を振込してもらい、振込確認する
    ⑨A3で２部プリントアウトして申込者に署名捺印してもらう
    ⑩申込用紙記入、入金確認、契約書署名捺印（借主）、免許証・車検証のコピーすべて揃ったら担当者へまわす
  • イタンジで申込受付できる場合は、イタンジから申込を進める
  • 紙の場合は申込用紙に記入してもらう
  • 保証委託申込書を用意して記入してもらう
  • 身分証（免許証・マイナンバーカード等）のコピーをとる
  • すべて揃ったら担当者へまわす
  • 個人 or 法人かを確認し、対応する申込用紙を用意する
  • 保証委託申込書を用意して記入してもらう
  • 法人の場合は謄本（登記事項証明書）のコピーをとる
  • 個人の場合は身分証のコピーをとる
  • すべて揃ったら担当者へまわす
  • 内見の日時・物件名・号室を確認する
  • 鍵の所在（キーボックス・管理会社・弊社管理など）を確認する
  • 持ち物を確認する（鍵・名刺・メジャー・スリッパなど）
  • 内見後はお客様の反応・ご意見をメモして担当者へ共有する
  • 鍵は必ず元の場所へ返却する
    【事前確認】
    物件名・号室・立会日時・契約者名を確認する
    契約書の特約を確認する
    持ち物を確認する
    【ポイント①】チェックポイント
    借主と一緒に確認（一緒に確認する）
    その場で説明する（後出しNG）
    写真・動画を必ず撮る
    👉 「その場で合意できるところは全部潰す
    ■ 壁・クロス
  • ヤニ → 借主負担
  • 画鋲程度 → 通常損耗
  • クギ穴 → 借主負担
  • 大きな穴 → 借主負担
  • 日焼け → 経年劣化
    • 👉 判断軸「普通に生活してたらつくか？」
    ■ 床（フローリング・CF）
  • 家具跡 → 通常損耗
  • 水シミ・腐食 → 借主
  • 焦げ → 借主
    • ■ 水回り（キッチン・風呂・トイレ）
  • 軽い汚れ → クリーニング範囲
  • カビ放置 → 借主負担
  • 尿石ガチガチ → 借主
    • 👉 「清掃で落ちるか」じゃなく「放置したか」がポイント
    ■ 設備（エアコン・給湯器など）
  • 壊れてる → 原則貸主
  • 使い方ミス → 借主
    • 【ポイント②】経年劣化 vs 過失の判断
  • 「これは通常損耗なので大丈夫です」
  • 「これは借主様のご負担になります」
  • 「ここはオーナーと相談します」
  • その場でチェックシート記入
    • 「こちらの汚れ（傷）は、通常使用を超えていると判断されるため、借主様のご負担対象となる可能性があります。」
    「こちらについては判断が分かれる部分になりますので、オーナー様とも確認のうえ、後日正式にご案内させていただきます。」
    「現時点では正確な金額は出せないため、お見積りを作成のうえ、後日ご説明させていただきます。」
  • 断定しすぎないで、可能性があるに留めるのもOk
    • 【立会終了】
  • 鍵の返却（スペアキーも全て）
  • 戸締りをする
  • ブレーカーを落とす
  • 施錠する
  • 原状回復が必要な箇所は社内共有し、見積依頼につなぐ
  • 写真・現況・修繕内容を整理する
  • 必要に応じて見積を取り、工事項目を明確にする
  • 依頼先・工期・費用の目安を確認する
  • 工事完了後は完了報告と書類整理を行う
